# EG Battery legal site

This repository contains the static bilingual legal website for EG Battery.

- `index.html`: landing page and developer/support contact
- `privacy.html`: bilingual privacy policy
- `terms.html`: bilingual terms of use
- `style.css`: shared responsive styling

Developer: Mohamed Elsamman · Support: `mohamed.elsamman.dev@gmail.com`

The app package described by the policy is `com.techs4arab.egybattery`, source version 1.0. Keep the policy in sync if permissions, data handling, services or dependencies change.

GitHub Pages should serve the `main` branch root. Until Pages is enabled and the HTTPS URLs are verified, the app intentionally retains its pending-publication notice and does not link to an unverified URL.
